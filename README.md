# ♟️ Chess System Java

Um sistema de xadrez desenvolvido em **Java**, criado durante meus estudos de Programação Orientada a Objetos.

O projeto simula uma partida de xadrez diretamente pelo terminal, aplicando conceitos como **herança, polimorfismo, encapsulamento, composição e tratamento de exceções**.

## 🎯 Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos de **Java e POO**, acompanhando o curso e implementando gradualmente as regras e estruturas necessárias para criar um sistema de xadrez.

A aplicação permite:

- Visualizar o tabuleiro no terminal
- Selecionar peças e realizar movimentos
- Validar movimentos possíveis
- Alternar entre jogadores
- Capturar peças adversárias
- Identificar movimentos possíveis de cada peça
- Trabalhar com posições do tabuleiro utilizando notação de xadrez

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/MegaPlys/chess-system-java.git
```

### 2. Entre na pasta

```bash
cd chess-system-java
```

### 3. Abra o projeto em uma IDE Java

Você pode utilizar IDEs como:

- Eclipse
- Spring Tool Suite
- IntelliJ IDEA

### 4. Execute a classe principal

Execute:

```text
Program.java
```

O jogo será iniciado diretamente pelo terminal.

## 🎮 Como jogar

Ao iniciar a aplicação, o tabuleiro será exibido no terminal.

Você poderá informar a posição da peça utilizando a notação tradicional de xadrez:

```text
Origem: e2
Destino: e4
```

O sistema verifica se o movimento escolhido é válido antes de executá-lo.
